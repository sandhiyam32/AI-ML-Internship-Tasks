# Feature Distribution Analysis

This project analyzes the distribution of numerical features using the California Housing Dataset.

## Features

* Mean and median calculation
* Skewness analysis
* Histogram with KDE
* Box plot visualization
* Outlier detection using IQR

## Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset

California Housing Dataset from Scikit-learn.



## Output

The program displays the statistical values and visualizations for the selected features. It also identifies skewed distributions and potential outliers.
