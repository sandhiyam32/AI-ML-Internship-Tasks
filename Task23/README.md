# Task 23 – K-Means Clustering

## Description
This task demonstrates K-Means Clustering, an unsupervised machine learning algorithm used to group similar data points into clusters.

## Dataset
Mall Customer Dataset

Features:
- Annual Income
- Spending Score

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## What I Did
1. Loaded the customer dataset.
2. Scaled numerical features using StandardScaler.
3. Applied the K-Means algorithm.
4. Grouped customers into 3 clusters.
5. Visualized the clusters using a scatter plot.
6. Analyzed the resulting customer groups.

## Key Learning
K-Means Clustering groups similar data points based on their distance from cluster centers.

## Conclusion
Learned how to implement K-Means Clustering and visualize customer groups using Python and Scikit-learn.
